# Tag Explorer — Future Ideas

> Ideas to explore after the core Tag Explorer page is implemented.
> Discussed during implementation planning on 2026-08-19.

## 1. Smart Tag Suggestions
When tags are selected, show a "Related tags" section that surfaces the most
co-occurring tags not yet selected — a recommendation engine for tag discovery.

## 2. Saved Tag Searches
Let users save tag combinations as named presets (e.g., "Nature photos" =
`outdoor` + `landscape` + `wildlife`). Persist in library settings.

## 3. Tag Statistics Dashboard
Aggregate stats: most used tags, orphan tags (0 entries), recently added tags,
tag growth over time.

## 4. Drag-to-Reorder Tag Hierarchy
Allow drag & drop in the Tree view to reparent tags, making taxonomy management
part of the exploration flow.

## 5. Faceted Count Updates
As tags are selected, update the entry counts on remaining tags to show how many
entries match the *intersection* of current selection + that tag. Creates a
faceted search experience like e-commerce filters.

## 6. Tag Color / Category Grouping
Group tags by their color category in all views, with collapsible sections per
category.

## 7. Quick Preview on Hover
Hovering a tag shows a small thumbnail grid of 4-6 sample entries with that tag,
giving a visual preview of what the tag contains.

## 8. Tag Relationship Graph Enhancements
- Cluster detection (auto-group tightly connected tags)
- Adjustable edge-weight threshold slider
- Zoom-to-fit on selection change
- Export graph as image
